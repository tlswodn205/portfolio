CASE 01. 슬로우 쿼리 및 DB 조회 구조 개선

PERFORMANCE
문제

운영 서비스 일부 조회 기능에서 실행시간이 길어지는 슬로우 쿼리가 발생했습니다.

분석

인덱스를 활용하지 못하는 조건, 불필요하게 넓은 조회 범위와 사용하지 않는 데이터 조회 구간을 확인했습니다.

개선

WHERE 조건과 조회 범위를 정리하고 불필요한 조회를 제거했으며, 병목 구간은 테이블 구조와 인덱스 구성을 함께 개선했습니다.

결과

개선 대상 슬로우 쿼리의 평균 실행시간을 약 80% 단축했습니다.

CASE 02. 검색엔진 적용 및 서비스 연동

SEARCH
탐색

데이터

검색엔진에서 사용할 데이터를 색인할 수 있도록 데이터베이스 View를 설계하고 구현했습니다.

연동

결과

기존 검색 방식 대비 검색 응답시간을 약 75% 단축했습니다.
